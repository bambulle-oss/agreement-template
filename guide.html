Agreement Template Creation

Guide de l'utilisateur — 20 septembre 2026 · English version below

Ce que fait l'application

Vous déposez un acte signé. L'application repère les éléments propres à l'opération — parties, représentants, adresses, numéros d'immatriculation, dates, montants, nombres de titres, coordonnées bancaires — et les remplace par des variables nommées. Vous obtenez un fichier Word réutilisable pour l'opération suivante.

Tout se passe dans la mémoire de votre Mac. Aucun document n'est transmis, à personne, y compris à l'éditeur.

Premiers pas

Ouvrez un acte de trois façons : glissez-le sur la fenêtre, cliquez sur Choisir un fichier…, ou utilisez le menu Fichier > Ouvrir un acte… (⌘O). Pour refermer le document et l'effacer de la mémoire : Fichier > Fermer le document (⇧⌘W).

Formats acceptés : Word .docx, .doc, .rtf, .odt, PDF texte, PDF scanné, images (PNG, JPEG, TIFF, HEIC) et texte brut. Les actes en français comme en anglais sont reconnus ; la langue est détectée à l'ouverture.

Seul le format .docx conserve la mise en forme d'origine. Pour les autres sources, l'application le signale sous le titre du document : le modèle produit reprend le texte, pas la présentation.

L'écran de travail

Le document occupe la partie gauche, chaque élément repéré surligné dans la couleur de son type et suivi du nom de variable proposé. La partie droite liste ces éléments groupés par type, avec le nombre d'occurrences de chacun.

En haut de la liste, un compteur indique par exemple 22 variable(s) · 30 remplacement(s). Le champ Filtrer… réduit la liste à ce que vous cherchez.

TypeExemples

SociétéDénominations sociales, avec ou sans forme juridique
Lieu · Adresse · Code postal et villeSièges sociaux, domiciles, lieux de naissance

Les dates et références des textes de loi cités dans l'acte sont volontairement laissées intactes : une directive ou un règlement n'est pas un élément propre à l'opération.

Comment les variables sont nommées

L'application lit les termes définis de l'acte — ci-après le « Cédant », (the "Seller") — et nomme les variables selon le rôle de chacun, dans la langue du document : [Dénomination du Cédant], [Siège du Cédant], [Date de naissance de l'Acquéreur]. Quand un rôle est identifié pour une personne physique exerçant une fonction, le titre est repris : [Président du Cédant]. À défaut de terme défini, les variables sont numérotées par type : [Lieu 1], [Montant 2].

Relire les détections

C'est l'étape qui compte. Cliquez sur un élément surligné dans le document, ou sur une ligne de la liste : l'inspecteur s'ouvre en haut à droite avec trois actions.

ActionEffet
RenommerChange le nom de la variable. Validez avec ↩. Deux lignes portant le même nom sont fusionnées — c'est ainsi qu'on réunit « M. Dupont » et « Jean-Marc Dupont » sous une seule variable.
Ignorer cette occurrenceLaisse cette apparition-là en clair, sans toucher aux autres.
Exclure partoutRetire l'élément du modèle : il restera en clair partout. Utile pour un mot repéré à tort.

La case à cocher devant chaque ligne a le même effet que Exclure partout, et la case en tête d'un groupe agit sur tout le type d'un coup.

Les éléments « à vérifier »

Quand la détection est incertaine, l'élément est marqué à vérifier, affiché en pointillés et décoché par défaut : il ne sera pas remplacé tant que vous ne l'aurez pas validé. C'est un choix délibéré — mieux vaut un oubli que vous corrigez qu'un remplacement que vous n'aviez pas voulu.

Créer une variable oubliée

Sélectionnez le texte dans le document. L'inspecteur bascule sur Sélection : donnez un nom, choisissez un type, puis Créer la variable et remplacer toutes les occurrences. Toutes les apparitions de ce texte dans l'acte seront traitées.

Produire le modèle

Trois options, sous la liste :

  • Surligner les variables en jaune dans le modèle — pour les repérer d'un coup d'œil à la rédaction suivante.
  • Supprimer les images (logos, signatures, tampons) — recommandé : une signature scannée identifie autant qu'un nom.
  • Ajouter en annexe la table des variables — la liste des variables en fin de document, sans les valeurs d'origine.

Cliquez sur Produire le modèle.

Lire le rapport

Le rapport annonce le nombre de variables et de remplacements, puis le contrôle résiduel. L'application relit tout le fichier produit — corps, en-têtes, pieds de page, notes, métadonnées, relations — et cherche si une valeur remplacée y subsiste.

Si une valeur subsiste, elle est nommée avec son emplacement. Les causes habituelles sont une occurrence que vous avez ignorée volontairement, ou du texte dans une zone non éditable : graphique, objet incorporé, image.

Le rapport indique aussi ce qui a été retiré : métadonnées, commentaires, révisions acceptées et texte supprimé purgé, liens hypertexte, images.

Ce contrôle ne porte que sur les éléments détectés ou ajoutés. Un nom non repéré, une clause propre à l'opération, un montage particulier ou un simple contexte peuvent permettre la ré-identification. La relecture humaine reste indispensable.

Les deux fichiers à enregistrer

Enregistrer le modèle (.docx) produit le document réutilisable.

Table de correspondance (confidentielle) produit un fichier CSV associant chaque variable à sa valeur d'origine. Ce fichier contient les données de l'acte. Il se conserve comme l'acte lui-même, jamais avec le modèle : c'est lui qui permettrait de défaire le travail.

PDF scannés et images

La reconnaissance de texte s'exécute sur votre Mac (Vision). Comptez une minute pour un PDF scanné de plusieurs pages. Le texte reconnu n'est jamais parfait : relisez-le avant de vous fier aux détections, et sachez que la mise en forme d'origine n'est pas reprise.

Essai et déblocage

L'application est gratuite. Trois actes peuvent être exportés en modèle sans rien payer. Ouvrir un acte, l'analyser et le relire restent gratuits en toutes circonstances : seul l'export est décompté.

Ré-exporter un acte déjà exporté — après correction d'une variable, par exemple — ne consomme pas un nouvel essai.

Au-delà, un achat unique débloque l'application définitivement : pas d'abonnement, pas de paiement à l'acte. L'achat vaut pour tous vos Mac connectés au même compte Apple. Restaurer mes achats, dans la fenêtre de déblocage ou dans le menu de l'application, le rétablit après une réinstallation ou sur une nouvelle machine.

Confidentialité

Aucune donnée collectée, aucune connexion réseau pour traiter vos documents, aucun historique. Seule une empreinte numérique des actes déjà exportés est conservée localement, pour ne pas décompter deux fois le même acte ; elle ne permet pas de reconstituer le document. Politique de confidentialité complète.

Ce que l'application ne fait pas

  • Elle ne réécrit pas les clauses propres à l'opération : une clause de earn-out taillée sur mesure reste telle quelle.
  • Elle ne garantit pas l'anonymisation au sens de la réglementation sur les données personnelles.
  • Elle ne fournit aucun conseil juridique.

C'est une aide à la rédaction. Le modèle produit engage celui qui le réutilise.

Agreement Template Creation

User Guide — 20 September 2026

What the app does

You drop in an executed agreement. The app finds the deal-specific details — parties, representatives, addresses, registration numbers, dates, amounts, numbers of securities, bank details — and replaces them with named variables. You get a Word file you can reuse for the next transaction.

Everything happens in your Mac's memory. No document is ever transmitted to anyone, including the publisher.

Getting started

Open an agreement in one of three ways: drag it onto the window, click Choose a file…, or use File > Open an agreement… (⌘O). To close the document and clear it from memory: File > Close document (⇧⌘W).

Accepted formats: Word .docx, .doc, .rtf, .odt, text PDF, scanned PDF, images (PNG, JPEG, TIFF, HEIC) and plain text. Agreements in English and in French are both supported; the language is detected on opening.

Only .docx preserves the original formatting. For other sources the app says so under the document title: the template keeps the text, not the layout.

The working view

The document fills the left side, each detected item highlighted in its type colour and followed by the proposed variable name. The right side lists those items grouped by type, with the number of occurrences of each.

A counter at the top of the list reads, for instance, 22 variable(s) · 30 replacement(s). The Filter… field narrows the list.

What the app detects

TypeExamples
PersonNames of parties, representatives, directors
CompanyCompany names, with or without legal form
Place · Address · Postcode and cityRegistered offices, residences, places of birth
DateSignature, birth and maturity dates
Amount · Number of securities · PercentagePrices, share capital, share counts, holdings

Dates and references of statutes and regulations cited in the agreement are deliberately left untouched: a directive is not a deal-specific detail.

How variables are named

The app reads the defined terms of the agreement — (the "Seller"), ci-après le « Cédant » — and names variables by role, in the language of the document: [Company name of the Seller], [Registered office of the Seller], [Date of birth of the Purchaser]. Where a role is identified for an individual holding an office, the title is carried over: [Director of the Seller]. Without a defined term, variables are numbered by type: [Place 1], [Amount 2].

Reviewing the detections

This is the step that matters. Click a highlighted item in the document, or a row in the list: the inspector opens at the top right with three actions.

ActionEffect
RenameChanges the variable name. Press ↩ to confirm. Two rows with the same name are merged — that is how you bring "Mr Smith" and "John Smith" under one variable.
Ignore this occurrenceLeaves that one appearance as it is, without touching the others.
Exclude everywhereRemoves the item from the template: it stays as it is throughout. Useful for a word picked up by mistake.

The checkbox on each row does the same as Exclude everywhere, and the checkbox on a group heading acts on the whole type at once.

Items marked "to check"

When a detection is uncertain the item is marked to check, shown with a dashed underline and left unchecked by default: it will not be replaced until you confirm it. This is deliberate — better an omission you catch than a replacement you did not intend.

Creating a variable the app missed

Select the text in the document. The inspector switches to Selection: give it a name, choose a type, then Create variable and replace all occurrences. Every appearance of that text in the agreement is handled.

Creating the template

Three options, below the list:

  • Highlight variables in yellow in the template — so they are obvious next time you draft.
  • Remove images (logos, signatures, stamps) — recommended: a scanned signature identifies as surely as a name.
  • Append the table of variables — the list of variables at the end of the document, without the original values.

Click Create template.

Reading the report

The report gives the number of variables and replacements, then the residual check. The app re-reads the whole output file — body, headers, footers, notes, metadata, relationships — looking for any replaced value that survived.

If one did, it is named with its location. The usual causes are an occurrence you chose to ignore, or text in a non-editable area: a chart, an embedded object, an image.

The report also states what was removed: metadata, comments, tracked changes accepted and deleted text purged, hyperlinks, images.

This check only covers detected or added items. An undetected name, a deal-specific clause, an unusual structure or plain context may still allow re-identification. Human review remains essential.

The two files to save

Save template (.docx) produces the reusable document.

Correspondence table (confidential) produces a CSV mapping each variable to its original value. That file contains the agreement's data. Keep it as you would keep the agreement itself, never alongside the template: it is what would undo the work.

Scanned PDFs and images

Text recognition runs on your Mac (Vision). Allow a minute for a scanned PDF of several pages. Recognised text is never perfect: read it before relying on the detections, and note that the original layout is not carried over.

Trial and unlock

The app is free. Three agreements can be exported as templates at no cost. Opening, analysing and reviewing an agreement are always free: only exporting is counted.

Re-exporting an agreement you already exported — after fixing a variable, say — does not use another trial.

Beyond that, a single purchase unlocks the app for good: no subscription, no per-document fee. The purchase covers every Mac signed in with the same Apple Account. Restore purchases, in the unlock sheet or in the app menu, brings it back after a reinstall or on a new machine.

Privacy

No data collected, no network connection to process your documents, no history. Only a digital fingerprint of already-exported agreements is stored locally, so the same agreement is not counted twice; it cannot be used to reconstruct the document. Full privacy policy.

What the app does not do

  • It does not rewrite deal-specific clauses: a bespoke earn-out stays exactly as drafted.
  • It does not guarantee anonymisation within the meaning of data-protection law.
  • It gives no legal advice.

It is a drafting aid. Whoever reuses the template answers for it.
